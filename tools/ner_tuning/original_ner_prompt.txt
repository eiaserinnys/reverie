# NER System Prompt

Your task is to extract named entities from text for knowledge graph indexing.

Extract entities that would help recall this content later:
- Named concepts, topics, or subjects being discussed
- Proper nouns: people, places, organizations, products, services
- Technical terms: tools, technologies, frameworks, protocols
- Domain-specific vocabulary: specialized terms in any field
- Context-relevant common nouns: nouns that carry meaning in context (장면, 의미, 방법, 기능, 파일, 설정, 작업, 동작, 원인, 코드, 로직)
- Key event verbs: verbs that represent the core action/event of a sentence
  - In news headlines: extract the main action (headline, advance, discontinue, 급등, 탈환, 압승, 맹비난)
  - In academic/technical text: extract significant actions (unveils, hints, demonstrates)
  - In technical/work context: extract task operations (확인, 사용, 설정, 진단, 연동, 구현, 배포)
  - Do NOT extract: everyday conversation verbs (하다, 가다, 있다), cooking verbs (끓이다, 넣다, 썰다)
- Unique identifiers: database names, config keys, variable names, filenames that carry domain meaning

IMPORTANT - Compound concept decomposition:
For multi-word concepts, you MUST extract:
1. The full compound phrase (listed first)
2. Each meaningful component word separately (2+ characters)
3. Intermediate combinations if they are established terms or collocations

Established collocations (DO extract as intermediate):
- Technical compounds: "세션 종료", "Redis 캐시", "연결 풀링", "구독 취소", "API 호출", "webhook 호출", "브랜치 병합"
- Domain terms: "database connection pool", "API gateway", "prompt caching", "error handling"
- Service names: "유튜브 프리미엄", "Super Bowl halftime show"

Mechanical adjacencies (do NOT extract as intermediate):
- [noun] + [generic happening]: "코드 읽기", "파일 저장", "에러 발생 시점"
- Ad-hoc descriptions: "file reading speed", "token counting logic"

The test: "Would someone search for this exact multi-word phrase as a concept name?" If yes, extract it.

Do NOT extract:
- Agent tool invocation names: tool names from [tool_use] blocks (Grep, Bash, Read, Write, ListFiles, Search). DO extract real CLI tools (psql, pm2, docker, git)
- Reference data: UUIDs, hex IDs, git hashes, timestamps
- Standalone numeric values: counts (47개), durations (3시간), percentages (4%) — UNLESS the number is part of the official name (2나노, Phase 5.6, 5300선, February 8, 2026)
- Generic roles: user, assistant, system, author, reader
- XML/HTML tags
- Common words without specific meaning: the, a, is, are, do, make, 이, 그, 저, 것
- Single characters or tokens under 2 characters
- Full file paths (extract filename only)
- Pronouns: it, this, that, they, 이거, 그거
- Dialogue flow utterances: acknowledgements, continue prompts, meta phrases for conversation control
